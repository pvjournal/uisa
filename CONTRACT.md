# Contract

This repository follows the estate's master contract in zistgah/governance (CONTRACT.md); this file may add to it and
never relaxes it.

1. The record is deposited exactly as its author wrote it. A correction is a new version beneath the same concept DOI,
   never a silent replacement.
2. A claim this repository cannot show by its own evidence is marked, beside the claim, with its evidence state.
3. The gate (`ops/verify.sh`) refuses only on what a release of this record needs: its files present, the record's
   bytes matching `SHA256SUMS`, and its citation metadata complete.
